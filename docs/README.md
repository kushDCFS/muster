# Pitch materials

## `pitch.html` — Blue Ocean pitch deck (14 slides)

Self-contained: no build step, no dependencies, no network calls. Open it in
any browser.

```
# macOS
open docs/pitch.html
# Windows
start docs/pitch.html
# Linux
xdg-open docs/pitch.html
```

**Navigation.** Scroll, or use `→` / `←` (also `PageUp` / `PageDown`). A
progress rail runs across the top and the slide counter sits bottom-right.

**Two slides are live, not screenshots.** Slide 7 shows real turnout figures
from 65,000 actual San Francisco dispatch records; slide 8 has a working
slider driving the real returns curve computed from that dataset. Drag it in
front of an audience rather than talking over a static image.

**Export to PDF.** `Cmd/Ctrl-P` → *Save as PDF*. Print rules lay it out one
landscape slide per page at 13.33 × 7.5in (standard 16:9), hide the scroll
chrome, and freeze the optimizer at its 20 hrs/week default. Enable
*Background graphics* in the print dialog or the slides will come out white.

**Themes.** Follows the viewer's light/dark preference. Dark tends to project
better in a dim room; light prints better.

## Editing

One file, plain HTML and CSS at the top, a small script at the bottom. The
returns-curve data on slide 8 is a literal array (`CURVE`) generated by
`model/optimizer.py` — regenerate it with:

```python
from model import audit, optimizer as opt
df, _ = audit.parse_upload(open("data/sf_ems_2024_real.csv","rb").read(), "sf.csv")
grid = opt.build_grid(audit.classify(df))
print([[p["hours"], p["coverage_pct"], p["annual_cost"]]
       for p in opt.returns_curve(grid)["points"]])
```

Slide 1 carries a `[ your team name ]` placeholder.

## A note on the numbers

Every statistic on a slide carries its source in the slide itself. Figures
drawn from this repo's own analysis (turnout medians, NFPA 1720 compliance,
the returns curve) are reproducible from `data/sf_ems_2024_real.csv` — they
are not illustrative. Where a claim rests on an assumption rather than a
measurement, the slide says so; see `data/DATA_SOURCES.md` for the full
real-vs-modeled ledger.
